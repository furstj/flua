Fortran wrapper to the Lua scripting language http://www.lua.org/

This module provides Fortran bindings to the Lua C API, allowing Fortran programs to interact with Lua scripts and manage Lua states.

The handle to the Lua state is represented as a C pointer (c_ptr) in Fortran. For more information on the Lua C API, refer to the official Lua manual

Note

This module targets the Lua 5.1 API on purpose, for compatibility with LuaJIT. Do not use functions introduced in Lua 5.2+ (e.g. lua_rawlen, luaL_len); use their 5.1 counterparts instead (e.g. lua_objlen).


Uses

    • iso_c_binding
