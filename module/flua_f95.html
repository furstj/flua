Fortran 95 api for flua library

This module provides a Fortran 95 helpers for the flua library. It contains functions for creating and managing Lua states, executing Lua code, and interacting with Lua variables.

Lua C-API bindings


Uses

    • iso_c_binding
    • flua_c
